# 職員検診 受検票作成システム

市役所職員を対象とした 4 検診（**胃がん検診／乳がん検診／子宮頸がん検診／生活習慣病健診**）の
受検票を、職員名簿 CSV から自動で作成・印刷するためのツールです。

現在 Access で行っている「様式への差し込み印刷」を置き換え、
**対象者の抽出・日程の割当・受検票の印刷・所属別の仕分け**までを一括で行えるようにすることを目的としています。

---

## 特徴（LGWAN 接続系での利用を前提とした設計）

- **単一 HTML ファイル**　`kenshin.html` ひとつで完結します。インストール不要、ブラウザで開くだけで動作します。
- **外部通信を一切行いません**　インターネット上のライブラリ（CDN）を読み込まず、外部への送信も行いません。
  ヘッドレスブラウザで検証済みです（file:// 以外への通信 0 件）。
- **サーバ不要**　庁内サーバの構築や、ソフトウェアのインストール申請が不要です。
- **個人情報を端末に保存しません**　名簿はブラウザのメモリ上でのみ処理します。
  端末に保存されるのは判定ルールと日程の設定のみです。

---

## 使い方

1. `kenshin.html` を職員 PC にコピーし、ダブルクリックでブラウザ（Microsoft Edge 等）で開きます。
2. 画面上部のタブに沿って進めます。

| タブ | 内容 |
|---|---|
| １. 名簿の読込 | 職員名簿 CSV を読み込み、列の対応付けを確認します |
| ２. 対象者の判定ルール | 4 検診それぞれの対象年齢・性別・実施間隔を設定します |
| ３. 日程・会場 | 実施日・会場・定員を登録し、対象者を自動で割り当てます |
| ４. 対象者の確認 | 人数と内訳を確認し、辞退者・休職者などを個別に除外します |
| ５. 印刷・出力 | 受検票・配布鑑を印刷し、名簿 CSV を出力します |

**動作確認だけしたい場合**は、１のタブで「サンプル名簿を読み込む」を押してください。
架空の職員 20 名のデータで、実際の個人情報を使わずに一通りの動作を試せます。

## 入力する名簿 CSV について

| 項目 | 必須 | 備考 |
|---|:---:|---|
| 職員番号 | ○ | 重複はエラーとして検出します |
| 氏名 | ○ | |
| カナ | | 並び順（カナ順）に使用します |
| 生年月日 | ○ | 年齢の算出に使用します |
| 性別 | ○ | `男`/`女`、`M`/`F`、`1`/`2` を判別します |
| 所属コード | | 仕分けの並び順に使用します |
| 所属名 | ○ | 配布鑑の単位になります |
| 雇用区分 | | 特定の区分を対象外にする場合に使用します |

- **列の名称は自由です。** 読込後に画面上で対応付けを指定できます（`フリガナ`・`所属`・`部署名` などは自動で推定します）。
- **文字コードは自動判別します。** Access／Excel の既定である **Shift_JIS** と **UTF-8** の双方に対応しています。
- **生年月日は次の形式を解釈できます。**
  `1985/4/1` ／ `1985-04-01` ／ `19850401` ／ `1985年4月1日` ／
  `昭和60年4月1日` ／ `S60.4.1` ／ `1985/04/01 0:00:00`（Access の日付型出力）

解釈できなかった行は取り込まずにエラー一覧へ分離し、画面と CSV で確認できます。
**取り込めなかった人が黙って対象から抜け落ちることはありません。**

`sample/` に動作確認用のサンプル名簿（Shift_JIS 版・UTF-8 版）を置いています。

## 出力されるもの

| 出力 | 内容 |
|---|---|
| 受検票 | A4 縦・1 ページに 2 枚付け。所属コード順／カナ順／受診日時順を選べます |
| 所属別 配布鑑（かがみ） | 所属ごとの配布枚数・氏名一覧・受領欄。束ねて配布する際の送り状になります |
| 対象者名簿 CSV | 検診別の対象者一覧（受診日・受付時間・会場を含む） |
| 所属別 集計 CSV | 所属 × 検診のクロス集計 |
| 未割当・エラー一覧 CSV | 取込エラー・定員不足による未割当・手動除外の一覧 |

PDF として保存する場合は、印刷ダイアログの送信先で「PDF として保存」を選んでください。

印刷イメージは `docs/` を参照してください。

- `docs/preview_ticket.png` … 受検票（A4 に 2 枚付け）
- `docs/preview_kagami.png` … 所属別 配布鑑
- `docs/印刷プレビュー_受検票サンプル.pdf` … サンプル名簿で出力した全 17 ページ

## 対象者の判定ルールについて

**初期値は暫定です。必ず貴市の実施要領で確認し、画面上で設定し直してください。**

職員検診の対象者基準は、**労働安全衛生法（国の法律）に基づく定期健康診断**として実施するものと、
**共済組合・互助会の事業**として実施するがん検診とで根拠が異なる場合があります。
どの根拠で実施している事業かを確認のうえ、年齢・性別・実施間隔を設定してください。

設定できる条件：

- 今年度実施するかどうか
- 対象年齢（下限・上限）
- 性別（男女とも／女性のみ／男性のみ）
- 実施間隔（毎年度／隔年・基準日年齢が偶数の人／隔年・奇数の人）
- 対象外とする雇用区分（部分一致・カンマ区切り）
- 前年度受診者名簿の読込による除外（隔年実施で受診歴により判定する場合）

年齢は「年齢の基準日」時点の満年齢で算出します（既定：年度末＝翌年 3 月 31 日）。

## 個人情報の取扱いに関する注意

健康診断・検診に関する情報は、**国の法令**である
**個人情報の保護に関する法律 第 2 条第 3 項**および**同法施行令 第 2 条第 2 号**により
**要配慮個人情報**に該当します。通常の職員名簿より厳格な取扱いが必要です。

健康診断の記録の保存については、**国の法令**である
**労働安全衛生法 第 66 条の 3** および **労働安全衛生規則 第 51 条**（健康診断個人票の 5 年間保存）
をご確認ください。

貴市の個人情報の保護に関する条例・規則および文書管理規程上の取扱いについては、
**例規集（条例規則／現行フォルダ）でご確認ください。本リポジトリでは確認・判断していません。**

本ツール自体は名簿を端末に保存しませんが、**出力した CSV・PDF の保存場所とアクセス権**は
庁の情報セキュリティポリシーに従って管理してください。

## 導入にあたって

1. **情報政策担当への確認**　`docs/情報政策担当への確認事項.md` のチェックリストをご利用ください。
   庁内で自作ツールを業務利用する場合、情報資産としての登録など所定の手続きが必要な場合があります。
2. **現行 Access との並走**　初回は必ず同じ名簿で両方から受検票を出力し、
   **対象者と印字内容が一致すること**を確認してから切り替えてください。
3. **1 検診から始める**　まず生活習慣病健診だけで通しで運用し、問題がなければ残り 3 検診へ展開する進め方を推奨します。

## 様式を変更したいとき

`kenshin.html` の以下の箇所を編集します。

| 変更したいこと | 編集箇所 |
|---|---|
| 枠線・文字サイズ・1 ページの枚数 | 先頭の `<style>` 内 `.ticket` の定義 |
| 印字する項目・並び | `buildTicketHTML()` 関数 |
| 配布鑑のレイアウト | `buildKagamiHTML()` 関数 / `.kagami` の定義 |
| 注意事項の文面 | アプリの「２. 判定ルール」画面（ファイルの編集は不要） |
| 検診の種類を増やす | 先頭の `KENSHIN` 配列と `defaultRules()` |
