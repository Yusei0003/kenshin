# 職員検診 受検票作成システム

市役所職員を対象とした 4 検診（**胃がん検診／乳がん検診／子宮頸がん検診／生活習慣病健診**）の
受検票を、職員名簿の Excel／CSV から自動で作成・印刷するためのツールです。

現在 Access で行っている「様式への差し込み印刷」を置き換え、
**対象者の抽出・日程の割当・受検票の印刷・所属別の仕分け**までを一括で行えるようにすることを目的としています。

---

## 特徴（LGWAN 接続系での利用を前提とした設計）

- **単一 HTML ファイル**　`kenshin.html` ひとつで完結します。インストール不要、ブラウザで開くだけで動作します。
- **外部通信を一切行いません**　インターネット上のライブラリ（CDN）を読み込まず、外部への送信も行いません。
  ヘッドレスブラウザで検証済みです（file:// 以外への通信 0 件）。
- **サーバ不要**　庁内サーバの構築や、ソフトウェアのインストール申請が不要です。
- **Excel をそのまま読めます**　SheetJS 等の外部ライブラリを使わず、ブラウザの標準機能だけで .xlsx を解析します。
- **この端末にデータを保存します**　読み込んだ職員名簿と予約状況はこのパソコンのブラウザ内に保存され、
  次に開いたとき自動で復元されます。外部へ送信されることはありません。
  LGWAN 接続系の専用端末での利用を前提とした設計です。

---

## 使い方

1. `kenshin.html` を職員 PC にコピーし、ダブルクリックでブラウザ（Microsoft Edge 等）で開きます。
2. 画面上部のタブに沿って進めます。

| タブ | 内容 |
|---|---|
| １. 名簿の読込 | 職員名簿（**Excel** ／ CSV）を読み込み、列の対応付けを確認します |
| ２. 予約状況の取込 | 検診ごとに予約状況ファイルを読み込み、確認が必要な件があれば表示します |
| ３. 対象者一覧 | **検診を選んで**、受検票が印刷される人を確認します。個別に外すこともできます |
| ４. 様式レイアウト | 協会の B4 用紙に重ねて印刷する位置を検診ごとに調整します |
| ５. 印刷・出力 | 受検票・配布鑑を印刷し、各種 CSV を出力します |

**動作確認だけしたい場合**は、１のタブで「サンプル名簿を読み込む」を押してください。
架空の職員 20 名のデータで、実際の個人情報を使わずに一通りの動作を試せます。

### 用意するのは 2 つのファイルだけです

**職員名簿** と **予約状況ファイル**（検診ごと）。

名簿の読込 → 予約状況の取込 → 印刷。
**受検票を印刷する人は予約状況ファイルだけで決まります。** 年齢や性別による絞り込みは行いません。

## 入力する職員名簿について

| 項目 | 必須 | 備考 |
|---|:---:|---|
| 職員番号 | ○ | 重複はエラーとして検出します |
| 氏名 | ○ | |
| カナ | | 並び順（カナ順）に使用します |
| 生年月日 | ○ | 年齢の算出に使用します |
| 性別 | ○ | **`1` = 男性／`0` = 女性**。`男`/`女`、`M`/`F`、`2`（女性）も判別します |
| 所属コード | | 仕分けの並び順に使用します |
| 所属名 | ○ | 配布鑑の単位になります |
| 雇用区分 | | 特定の区分を対象外にする場合に使用します（`区分名`・`身分` も自動認識） |
| 在職 | | `1` 以外の職員を対象から外せます（チェックボックスで切替） |
| 組合員証記号番号 | | 受検票に印字します（名簿の `社保` 列を自動認識） |
| 係名 | | 受検票に印字したい場合に使用します |

- **Excel（.xlsx）をそのまま読み込めます。** 外部ライブラリを使わず、ZIP の展開と XML の解析を
  ブラウザの標準機能だけで行っています（LGWAN では CDN からライブラリを読み込めないため）。
  シートと見出し行は画面上で選べます。
- **列の名称は自由です。** 読込後に画面上で対応付けを指定できます
  （`番号`・`ﾌﾘｶﾞﾅ`・`所属CD`・`区分名` などは自動で推定します）。
- **CSV の文字コードは自動判別します。** Access／Excel の既定である **Shift_JIS** と **UTF-8** の双方に対応しています。
- **生年月日は次の形式を解釈できます。**
  `1985/4/1` ／ `1985-04-01` ／ `19850401` ／ `1985年4月1日` ／
  `昭和60年4月1日` ／ `S60.4.1` ／ `1985/04/01 0:00:00`（Access の日付型出力）／
  **Excel の日付セル（和暦表示・シリアル値を含む）**
- **性別**は名簿のコード **`1` = 男性／`0` = 女性** を判別します（`男`/`女`、`M`/`F`、`2` も可）。
- **カナ**は半角（`ﾜﾀﾞ ﾕｳｾｲ`）でも全角（`ワダ ユウセイ`）に直して取り込みます。

解釈できなかった行は取り込まずにエラー一覧へ分離し、画面と CSV で確認できます。
**取り込めなかった人が黙って対象から抜け落ちることはありません。**

`sample/` に動作確認用のサンプルを置いています（すべて架空のデータです）。

| ファイル | 内容 |
|---|---|
| `職員名簿_サンプル.xlsx` | 41 列の職員名簿。和暦表示の日付セル・半角カナ・性別コード（1/0）を含みます |
| `予約状況_胃がん検診_サンプル.xlsx` | `【男】6日（火）　7：00〜7：15` 形式。「印刷不要」の文言・空欄も混在 |
| `予約状況_婦人検診_サンプル.xlsx` | `09:30〜09:45（35歳以上）` 形式。年齢区分が混在 |
| `職員名簿_サンプル_SJIS.csv` / `_UTF8.csv` | CSV 版 |

## 予約状況ファイルについて

**職員番号と「入力」欄をもつファイル**を検診ごとに読み込みます。
**誰の受検票を印刷するかは、このファイルだけで決まります。**

ファイルは **取込元ごと**に読み込みます。

| 取込元 | 対象になる検診 | 入力欄の例 | 画面で指定するもの |
|---|---|---|---|
| **胃がん検診** | 胃がん検診 | `【男】6日（火）　7：00〜7：15` | **実施年月**（入力欄に日しかないため）・会場 |
| **婦人検診** | 乳がん検診・子宮頸がん検診 | `09:30〜09:45（35歳以上）` | **受診日**（入力欄に日付がないため）・会場・年齢区分の振り分け |

入力欄には、職員が予約すると予約時間などが入ります。
**印刷しないのは次の 2 つだけで、それ以外はすべて印刷します。**

| 入力欄の内容 | 受検票 | 印字のされ方 |
|---|---|---|
| `【男】6日（火）　7：00〜7：15` | 印刷する | 受診日「10月6日（火）」（実施年月の指定から）／受付時間「7：00〜7：15」 |
| `09:30〜09:45（35歳以上）` | 印刷する | 受診日は指定した日／受付時間「09:30〜09:45」 |
| `8/22　10：30〜10：50` | 印刷する | 受診日「8月22日（土）」／受付時間「10：30〜10：50」 |
| `要相談` など日時として読めない内容 | **印刷する** | 受診日は空欄／受付時間に内容をそのまま印字（一覧に**要確認**と表示） |
| `派遣元自治体で受診` `派遣元で受診` `他受診機関で受診` `他の受診機関で受診予定` `受診しない` | **印刷しない** | ― |
| **空欄** | **印刷しない** | ― |

### 全角・半角はどちらでも読み取れます

数字（`６日` と `6日`）、コロン（`７：００` と `7:00`）、かっこ（`（火）` と `(火)`）、
`【男】` と `[男]`、区切りの `〜 ～ - ー` などが混ざっていても構いません。
**受付時間は元の表記のまま印字します**（全角のコロンは全角のまま）。

読み取れる日付の書き方：`6日（火）` ／ `6（火）` ／ `10月6日` ／ `10/6` ／ `10-6`

### 婦人検診の振り分け

入力欄の年齢区分によって、どの検診の受検票を印刷するかが決まります。
初期値は次のとおりで、**画面上で追加・変更できます**。

| 入力欄に含まれる文字 | 乳がん検診 | 子宮頸がん検診 |
|---|:---:|:---:|
| `35歳以上` | ○ | ○ |
| `20歳以上` | ― | ○ |

どのルールにも当てはまらないとき（年齢区分が書かれていない場合を含む）の扱いは
「両方に含める（要確認として表示）」「子宮頸がん検診のみ」「対象外にする」から選べます。

### 入力欄の内容を突き合わせて確認します

- **性別**　入力欄の `【男】` `【女】` が名簿の性別と違うときは要確認として表示します。
- **曜日**　入力欄の `（火）` が、指定した実施年月から計算した曜日と違うときは要確認として表示します。
- **受診日**　日付が決まらないときは要確認として表示します（受検票の受診日欄は空欄で印刷されます）。

- 「印刷が不要になる入力値」は画面上で**追加・変更できます**。判定は**部分一致**で、全角・半角と空白の違いは無視します。
- 西暦は対象年度から決まります（4〜12 月は年度の年、1〜3 月は翌年）。
- ファイルを読み込んでいない検診は対象者 0 名になります。
- 実施年月・受診日・会場・振り分けルールを変えると、取り込み済みの内容をその場で解釈し直します。
- 会場は取込画面で指定するか、ファイルに会場列があればその列を指定できます。

### 黙って対象から抜け落ちないようにしています

次の 4 つは、件数と明細を画面と CSV の両方で確認できます。**印刷前に必ずご確認ください。**

1. **要確認** … 入力欄を受診日時として読み取れなかった人（**印刷はされます**）
2. **名簿と突合できない職員番号** … 名簿にいない、または在職欄により除外された人
3. **職員番号の重複** … 複数行ある場合は最後の行を採用し、該当の職員番号を表示します
4. **名簿の取込エラー** … 生年月日や性別を解釈できなかった行

## 受検票の印刷（B4 用紙への重ね刷り）

岩手県対がん協会から届く **B4（364 × 257mm）の用紙**に、氏名・所属・生年月日などを重ねて印刷します。
用紙は左半分が「受検票」、右半分が「電算処理用紙」で、**1 人あたり B4 1 枚**です。

印字する項目と位置は検診ごとに異なるため、**胃がん・乳がん・子宮頸がんの 3 種類を個別に用意**しています。
初期値は現行の印刷物（Access からの出力 PDF）から mm 単位で実測した座標です。

**生活習慣病健診は受検票を印刷しません。** 対象者の把握・集計・CSV 出力には引き続き使えます。

### 印字される内容

団体名（陸前高田市）／部課名・分署名／フリガナ／氏名／性別の○／
生年月日の元号の○・年・月・日／年齢／組合員証記号番号

- **性別と元号の○は文字ではなく図形**として描いています。フォントによって潰れたりずれたりしません。
- 年齢の基準日は検診ごとに選べます（既定は**年度初日（4 月 1 日）現在**）。
- フリガナは名簿の表記のまま（半角カナ）印字します。

### 印刷時の注意

印刷ダイアログで **「倍率：100％（実際のサイズ）」「用紙に合わせる：オフ」「余白：なし」**
に設定してください。これを忘れると位置がずれます。

## 様式レイアウトの調整

用紙や印刷機との相性で位置がずれる場合、**「３. 様式レイアウト」画面で調整できます。**
ファイルを書き換える必要はありません。

| できること | 操作 |
|---|---|
| 全体が一様にずれている | 「全体のずれ補正」に横・縦のずれ（mm）を入力 |
| 特定の項目だけ合わない | 用紙の絵の上で**その項目をドラッグ** |
| 細かく詰める | 項目を選んで**矢印キー**（0.5mm）／**Shift ＋ 矢印**（0.1mm） |
| 文字の大きさ・字間・太字を変える | 項目を選んで数値を入力 |
| ○の大きさを変える | 項目を選んで幅・高さ・線の太さを入力 |
| 項目を増やす・減らす | 「＋ 文字の項目を追加」「＋ ○囲みを追加」／「この項目を削除」 |
| 位置合わせを目で確認する | 用紙をスキャンした画像を読み込み、薄く重ねて表示（印刷はされません） |
| 引き継ぐ・別の端末で使う | 「レイアウトをファイルに書き出す」／「ファイルから読み込む」 |

**位置合わせの手順**

1. 「位置合わせ用に1枚テスト印刷」で、10mm の方眼と目盛を重ねた 1 枚を実際の用紙に印刷します。
2. ずれを定規で測り、「全体のずれ補正」に入力します（右にずらしたいなら横をプラス、下なら縦をプラス）。
3. 個別の項目だけ合わない場合はドラッグで動かします。
4. 「この設定を保存」を押すと、次回以降も同じ位置で印刷されます。

差し込める項目：団体名／所属名／所属コード／係名／職員番号／氏名／カナ／カナ半角／
組合員証記号番号／性別／元号／和暦年／生月／生日／西暦年／生年月日／年齢／
受診日／受診月／受診日日／受付時間／会場／年度／和暦年度

## 並び順

受検票の印刷と対象者一覧では、次の並び順を選べます。

| 並び順 | 基準 |
|---|---|
| **職員番号順** | 名簿の **A 列（番号）**。数字は数値として並びます（9 → 10 → 100） |
| **所属コード順** | 名簿の **M 列（所属CD）** → 同じ所属の中は職員番号順。配布の仕分けに便利です |
| カナ順 | 名簿のフリガナ |
| 受診日時順 | 予約状況ファイルの受診日・受付時間。当日の受付順に並びます |

## 出力されるもの

| 出力 | 内容 |
|---|---|
| 受検票（B4 重ね刷り） | 協会の用紙に重ねて印刷。1 人 1 枚。**職員番号順／所属コード順**／カナ順／受診日時順を選べます |
| 受検票（A4 自前様式） | 用紙がないときの予備。枠ごと印刷し、1 ページに 2 名分 |
| 所属別 配布鑑（かがみ） | 所属ごとの配布枚数・氏名一覧・受領欄。束ねて配布する際の送り状になります |

| 所属別 集計 CSV | 所属 × 検診のクロス集計 |
| 要確認・対象外一覧 CSV | 要確認（印刷はされます）・印刷しない人・名簿と突合できない番号・在職除外・取込エラーの一覧 |

PDF として保存する場合は、印刷ダイアログの送信先で「PDF として保存」を選んでください。

-## 個人情報の取扱いに関する注意

健康診断・検診に関する情報は、**国の法令**である
**個人情報の保護に関する法律 第 2 条第 3 項**および**同法施行令 第 2 条第 2 号**により
**要配慮個人情報**に該当します。通常の職員名簿より厳格な取扱いが必要です。

健康診断の記録の保存については、**国の法令**である
**労働安全衛生法 第 66 条の 3** および **労働安全衛生規則 第 51 条**（健康診断個人票の 5 年間保存）
をご確認ください。

貴市の個人情報の保護に関する条例・規則および文書管理規程上の取扱いについては、
**例規集（条例規則／現行フォルダ）でご確認ください。本リポジトリでは確認・判断していません。**

### この端末に保存されるもの

読み込んだ**職員名簿と予約状況は、このパソコンのブラウザ内に保存されます**（外部へは送信されません）。
次に開いたときは自動で復元されるため、ファイルを読み直す必要はありません。

- **共用のパソコンでは使わないでください。**
- 年度の作業が終わったら「１. 名簿の読込」画面の**「保存データを消去」**を押してください。
- ブラウザの閲覧データを消去すると保存内容も消えます。元の Excel ファイルは別に保管してください。
- **出力した CSV・PDF の保存場所とアクセス権**も、庁の情報セキュリティポリシーに従って管理してください。

## 導入にあたって

0. **様式の位置合わせ**　`docs/様式レイアウトの調整手順.md` に沿って、協会の用紙に1枚テスト印刷してください。
1. **情報政策担当への確認**　`docs/情報政策担当への確認事項.md` のチェックリストをご利用ください。
   庁内で自作ツールを業務利用する場合、情報資産としての登録など所定の手続きが必要な場合があります。
2. **現行 Access との並走**　初回は必ず同じ名簿で両方から受検票を出力し、
   **対象者と印字内容が一致すること**を確認してから切り替えてください。
3. **1 検診から始める**　まず1検診だけで通しで運用し、問題がなければ残りへ展開する進め方を推奨します。

## 様式を変更したいとき

`kenshin.html` の以下の箇所を編集します。

## 動作確認済みの環境

Chromium（Microsoft Edge と同じ描画エンジン）でヘッドレス実行し、次を確認しています。

- **実際の職員名簿 Excel（41 列）** からの列の自動推定、和暦表示の日付セル・半角カナ・性別コードの変換
- **実際の予約状況ファイル**（`8/22　10：30〜10：50`）からの受診日時の読み取りと受検票への反映
- 5 つの「印刷が不要になる入力値」と空欄だけが印刷対象外になり、**それ以外はすべて印刷される**こと
- 入力欄の 21 通りの書き方（全角・半角の混在、`【男】6日（火）` 形式、`09:30〜09:45（35歳以上）` 形式、
  日付だけ／時刻だけ／読み取れない内容）を正しく解釈すること
- 婦人検診 1 ファイルから、年齢区分に応じて乳がん検診・子宮頸がん検診へ振り分けられること
- 性別の食い違い・曜日の食い違いを検出すること
- 職員番号順・所属コード順の並び替え（数字を数値として扱うこと）
- 全角数字（`９/３　９：００〜９：２０`）、`10月5日 13:00〜13:20` 形式の解釈
- 空欄・判別不能・職員番号の重複・名簿にない職員番号の検出
- 性別コード（1 = 男性／0 = 女性）の判別
- **職員名簿と予約状況を端末に保存し、開き直して復元**したうえで、印字内容と印字位置が一致すること
- 保存データの消去
- 受検票・配布鑑の生成、各種 CSV 出力
- **外部への通信が 0 件**であること

**B4 重ね刷りの位置**は、本システムの出力 PDF から座標を再測定し、
現行の印刷物と照合して検証しています。

| 検診 | 横方向のずれ | 縦方向のずれ |
|---|---|---|
| 胃がん検診 | 最大 0.04mm | 最大 0.29mm |
| 乳がん検診 | 最大 0.09mm | 最大 0.26mm |
| 子宮頸がん検診 | 最大 0.09mm | 最大 0.26mm |

あわせて、協会の用紙（見本）の画像に出力を重ね合わせ、
各項目が記入欄に正しく収まることを目視で確認しています。
性別と元号の○については、用紙上の「男・女」「昭和・平成」の位置を実測し、
確実に囲むよう初期値を調整しています。

利用できない環境向けに純粋な JavaScript の DEFLATE 展開処理を内蔵しています。
