予約状況ファイルの取込

職員番号と「入力」欄をもつファイル（Excel／CSV）を読み込みます。 入力欄には、職員が予約すると予約時間などが入ります。

予約状況ファイルの作り方　人事システムの 「ヨ　予約管理」 を開き、 「入力結果○　その１」 を選びます。表示された一覧の上で Ctrl ＋ A を押して すべて選択・コピーし、Excel に貼り付けて保存します。そのファイルをここで読み込みます。
受検票を印刷する人は、このファイルだけで決まります。
入力欄が 空欄 の人と、下の「印刷が不要になる入力値」に該当する人は印刷しません。 それ以外は、入力欄の内容にかかわらずすべて印刷します。
婦人検診は1つのファイルから、年齢区分に応じて乳がん検診・子宮頸がん検診に振り分けます。
日付は入力欄に書かれているものをそのまま使います。年や月を入力する必要はありません。

受検票の印刷が不要になる入力値

1行に1つずつ記載してください。部分一致で判定し、全角・半角と空白の違いは無視します。

ここに書いた文言に部分一致する人と、入力欄が空欄の人だけが印刷対象外です。 それ以外は、日時として読み取れない書き方でも印刷されます （日時として読み取れなかった場合は、入力欄の内容をそのまま受付時間欄に印字します）。

対象者一覧

検診を選ぶと、その検診で受検票が印刷される人を確認できます。

「対象」のチェックを外すと、その人の受検票は印刷されません（個別の辞退・休職者等の除外に使用）。

様式レイアウト（用紙への重ね刷り位置）

岩手県対がん協会から送られてくるB4の用紙に重ねて印刷するための位置を、検診ごとに設定します。
初期値は現行の印刷物から実測した座標です。用紙や印刷機との相性でずれる場合は、ここで調整してください。

すべての検診の「団体名」欄に共通で使われます。
生活習慣病健診は受検票を印刷しません。 対象者の把握とCSV出力には引き続き使えます。

位置合わせの手順

  1. 方眼を重ねて1枚テスト印刷します（下のボタン）。実際の用紙に印刷し、ずれを定規で測ります。
  2. 測ったずれを「全体のずれ補正」に入力します（右にずらしたいなら横をプラス、下なら縦をプラス）。
  3. 個別の項目だけ合わない場合は、用紙の絵の上でその項目をドラッグします。
  4. 合ったら「この設定を保存」を押します。次回以降も同じ位置で印刷されます。
印刷ダイアログの設定を必ず確認してください。 「倍率：100％（実際のサイズ）」「用紙に合わせる：オフ」「余白：なし」にしないと位置がずれます。
担当者が替わるときや、別の端末で使うときの引き継ぎに使えます。

位置合わせ用の画像について

対がん協会の用紙をスキャナで読み取って画像（PNG／JPEG）にし、「位置合わせ用の画像を読み込む」から取り込むと、 用紙の絵の上に薄く重ねて表示され、目分量で合わせられます。
スキャンは原寸（等倍）で、用紙の四隅が切れないように読み取ってください。 この画像は画面表示にのみ使い、印刷されません。保存もされません（タブを閉じると消えます）。

受検票の印刷

A4 自前様式に印刷する注意事項
1行に1つずつ書くと、番号付きの箇条書きで印刷されます。B4の重ね刷りでは使いません。
重ね刷りの注意
ボタンを押すと PDFファイルがダウンロードされます。そのPDFを開いて、協会の用紙に印刷してください。
印刷時は 「倍率：100％（実際のサイズ）」「用紙に合わせる：オフ」「用紙サイズ：B4」 に設定してください。これを忘れると位置がずれます。
まず数枚を白紙に印刷し、用紙と重ねて位置を確認することをおすすめします。

所属別 配布鑑（かがみ）だけを印刷

所属ごとに、配布する受検票の枚数と氏名一覧、受領欄を印刷します。束ねて回議・配布する際の送り状になります。

CSV出力

Excelで開ける形式（BOM付きUTF-8）で出力します。集計や当日の受付名簿にご利用ください。

作業の流れ

  1. 名簿の読込　上で作った職員名簿の Excel を読み込み、列の対応付けを確認します。
  2. 予約状況の取込　胃がん検診・婦人検診それぞれの Excel を読み込み、職員番号の列と入力の列を指定して取り込みます。
    取り込むと、確認が必要な件があればこの画面に表示されます。
  3. 対象者一覧　検診を選んで、受検票が印刷される人を確認します。辞退者などはここで個別に外せます。
  4. 様式レイアウト　初回のみ、協会の用紙に1枚テスト印刷して位置を確認します。合っていればそのままで構いません。
  5. 印刷・出力　並び順を選んで「受検票のPDFを作成」を押すと、PDFファイルがダウンロードされます。 そのPDFを開いて、協会の用紙に印刷してください。
誰の受検票を印刷するかは、予約状況ファイルだけで決まります。
入力欄が空欄の人と、「印刷が不要になる入力値」に該当する人は印刷しません。 それ以外はすべて印刷します。年齢や性別による絞り込みは行いません。

読み込んだ職員名簿と予約状況は、このパソコンのブラウザ内に保存されます。 次に開いたときは自動で復元されるので、ファイルを読み直す必要はありません。

保存されるもの消し方

検診の情報は要配慮個人情報にあたります。共用のパソコンでは使わないでください。 年度の作業が終わったら「保存データを消去」を押してください。

運用上の注意

印刷したら、対象者が正しく印刷されているか必ず確認してください。 「３. 対象者一覧」で検診ごとの人数と内訳を確かめ、印刷した束の枚数と突き合わせるのが確実です。 要確認の件がある場合は、その内容もあわせてご確認ください。
現行の Access と並走させる必要はありません。
LGWAN接続系での動作について
このファイルはインターネット上の部品を一切読み込まず、外部への通信も行いません。 ブラウザ（Microsoft Edge等）でファイルを開くだけで動作し、インストールは不要です。
なお、庁内で自作ツールを業務利用する場合、情報資産としての登録など所定の手続きが必要な場合があります。 利用前に情報政策担当にご確認ください。
個人情報の取扱い
健康診断・検診に関する情報は、国の法令である個人情報の保護に関する法律 第2条第3項および 同法施行令 第2条第2号により要配慮個人情報に該当します。 通常の職員名簿より厳格な取扱いが必要です。
また、健康診断の記録の保存については、国の法令である労働安全衛生法 第66条の3および 労働安全衛生規則 第51条（健康診断個人票の5年間保存）をご確認ください。
貴市の個人情報保護に関する条例・規則および文書管理規程上の取扱いについては、 例規集（条例規則／現行フォルダ）でご確認ください。本システムでは判断できません。
予約状況ファイルの取扱い
「受診しない」「他の受診機関で受診予定」といった入力欄の内容は、その職員の受診行動に関する情報です。 職員名簿と同様、このパソコンのブラウザ内に保存されます（外部へは送信されません）。 年度の作業が終わったら「保存データを消去」を押し、 元のExcelファイルや出力したCSVの保存場所・アクセス権とあわせてご注意ください。

受検票の印刷について

印刷のしかたは2通りあります。

様式用紙内容
B4 の用紙に重ね刷り 協会から届く B4 の用紙 受検票と電算処理用紙の記入欄に、氏名・所属・生年月日などを重ねて印刷します。1人あたり1枚。
ボタンを押すとPDFファイルがダウンロードされます。位置は「様式レイアウト」画面で調整できます。
A4 の自前様式 普通紙 A4 用紙がないときの予備。枠ごと印刷するので1枚で完結します。1ページに2名分。
生活習慣病健診は受検票を印刷しません。 対象者の把握、所属別の集計、CSV出力には引き続き使えます。 印刷が必要になった場合は、A4 の自前様式が利用できます（「印刷する検診」の一覧に戻すには設定の変更が必要です）。
PDFについて　外部のソフトやライブラリを使わず、このファイルの中だけで作っています。 フォントの埋め込みが不要な作り方にしているため、この端末のフォントでそのまま正しく出力されます。
画質は 200／300／400 dpi から選べます（初期値は 300 dpi）。 1枚あたり 30KB 程度、200名分でおよそ 6MB・15秒が目安です。
PDFの中では文字は画像として記録されるため、PDF上での文字検索やコピーはできません。印刷する分には問題ありません。
用紙に直接印刷したい場合は「ブラウザの印刷画面を開く」をお使いください。

A4 自前様式の枠線・文字サイズは、このファイル内の <style> 内 .ticket と buildTicketHTML() を編集すると変えられます。 注意事項の文面は「５. 印刷・出力」画面で A4 自前様式を選ぶと編集できます（ファイルの編集は不要です）。
